# Ademola Adedoyin — Portfolio

Personal portfolio website showcasing selected engineering work, backend systems, distributed architecture, fintech experience, and cloud infrastructure.

## Planned stack

- Next.js
- TypeScript
- Tailwind CSS
- Vercel

## Focus

The site is being built as a recruiter-facing portfolio with concise case studies, selected projects, engineering strengths, and clear links to GitHub and professional contact channels.
